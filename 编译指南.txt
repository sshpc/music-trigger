# ============================================
# Music Trigger - 一键编译指南
# ============================================

## 方案一：Android Studio 图形界面（推荐）

1. 打开 Android Studio
2. 选择 "Open" → 导航到 C:\Users\Administrator\.qclaw\workspace\MusicTrigger
3. 等待 Gradle 同步（首次会自动下载 Gradle Wrapper，约 5-10 分钟）
4. 同步成功后，点击菜单: Build → Build Bundle(s) / APK(s) → Build APK(s)
5. 编译完成的 APK 在: app\build\outputs\apk\debug\app-debug.apk

## 方案二：直接运行编译

项目已配置好，直接双击运行 build.bat 即可（需要网络下载 Gradle）

## 工作原理

MainActivity.java 实现：
1. onCreate() 被调用
2. 请求 AudioFocus（音频焦点）
3. 发送 MEDIA_PLAY 键事件触发系统播放音乐
4. 300ms 后调用 finish() 立即关闭

这样用户点击图标 → 音乐响起 → 应用消失
